# MarvelHeroes UD2 — Starter

Abre esta carpeta completa en Android Studio. Ejecuta `flutter pub get`, `flutter gen-l10n` y `flutter run` en un Android.
Referencia: Flutter 3.47.5 / Dart 3.13.4. No cambies versiones durante el laboratorio.
Los retos R1–R6 se describen en los libros y el enunciado. La base abre el detalle y muestra una interfaz completa; búsqueda, favoritos, dos columnas y cuatro traducciones están pendientes deliberadamente.
Los favoritos viven en memoria: cerrar el proceso elimina la selección. No hay autenticación, API remota ni almacenamiento.
Para empaquetar: `flutter build apk --debug`. Resultado: `build/app/outputs/flutter-apk/app-debug.apk`.
Este APK es de aula. La firma de producción y la publicación en tiendas no forman parte de UD2.
Los recursos gráficos proceden del backup del laboratorio del docente; véase PROCEDENCIA.md. No se atribuye una licencia abierta a las imágenes.
